# Rolls Bar — простая инструкция по админке

Updated: 2026-10-09

Эта инструкция предназначена для владельца/оператора ресторана. Она описывает только ежедневную работу с сайтом и не требует понимания WordPress-разработки.

## Вход

Staging до запуска:
- `https://staging.rollsbar.ru/wp-admin/`
- пользователь: `rollsbar_staging_admin`
- пароль хранится отдельно и не должен пересылаться в открытых чатах.

После запуска рабочий адрес админки будет тем же `/wp-admin/`, но уже на основном домене.

## С чего начинать

После входа откройте слева **Rolls Bar → Главная**.

На главном экране собраны основные действия:
- **Заказы**
- **Товары и цены**
- **Отзывы**
- **Акции и промо**
- **Вакансии**
- **Доставка**
- **Фото и файлы**
- **Контакты и checkout**

Для обычной ежедневной работы чаще всего нужны первые три раздела: заказы, товары и отзывы.

## Заказы

Откройте **Rolls Bar → Главная → Заказы**.

В списке заказов дополнительно видны:
- имя клиента;
- телефон;
- адрес;
- зона доставки / самовывоз;
- время заказа.

Откройте конкретный заказ, чтобы увидеть:
- состав заказа;
- сумму;
- способ получения;
- адрес;
- подъезд;
- код двери / домофона;
- этаж;
- квартиру / офис;
- комментарий клиента;
- состояние Telegram-уведомления, когда Telegram будет подключён.

Статусы заказа меняются штатными средствами WooCommerce. Не удаляйте реальные заказы без необходимости.

## Товары и цены

Откройте **Товары и цены**.

В карточке товара можно менять:
- название;
- цену;
- описание;
- фото;
- состав;
- вес / объём;
- калории;
- белки;
- жиры;
- углеводы;
- статус публикации.

Не создавайте дубли одного товара только ради изменения цены или фотографии — редактируйте существующую карточку.

## Отзывы

Новые отзывы не обязаны сразу становиться публичными. Откройте **Отзывы** и проверьте их перед публикацией.

Можно:
- посмотреть текст;
- увидеть рейтинг;
- посмотреть прикреплённое фото;
- опубликовать одобренный отзыв;
- оставить неподходящий отзыв неопубликованным.

## Акции и промо

Раздел **Акции и промо** управляет промо-карточками сайта.

Используйте его для уже согласованных акций/сообщений. Не публикуйте технические заметки или незавершённые черновики.

## Вакансии

В разделе **Вакансии** можно публиковать и снимать актуальные позиции.

Финальная анкета кандидата пока не включена: её текст и канал получения ответов должны быть отдельно подтверждены клиентом. Публичная страница при этом уже работает без технических заглушек.

## Доставка

В разделе **Доставка** уже есть пороги минимального заказа и техническая возможность хранить границы зон.

Важно: точные границы зон пока не утверждены клиентом, поэтому автоматическое определение зоны/минимальной суммы по полигону **не включено**.

Не рисуйте границы приблизительно. После получения точных границ они будут добавлены и проверены отдельно.

## Контакты и checkout

На главном экране Rolls Bar можно изменить:
- телефон;
- город;
- адрес;
- ссылки Telegram / VK;
- обязательность полей «Подъезд», «Домофон», «Этаж», «Квартира / офис».

После изменения нажмите **Сохранить изменения**.

## Уведомления

На главной панели показывается понятное состояние интеграций без отображения секретов.

### Email
До получения рабочей почты клиента панель показывает, что адрес ожидается. После подключения требуется один настоящий тестовый заказ и подтверждение фактического получения письма оператором.

### Telegram
Telegram обязателен для первого запуска по текущему решению владельца проекта.

После подключения оператор будет получать:
- номер заказа;
- сумму;
- способ получения;
- состав заказа;
- имя;
- телефон;
- адрес;
- дополнительные адресные поля;
- комментарий клиента.

Токен Telegram-бота не должен храниться в WordPress-тексте, Git или обычной переписке.

### Яндекс Метрика
Для текущего запуска не обязательна. Интеграция подготовлена, но подключается позже отдельной работой, если клиент её закажет.

## Что владельцу сайта лучше не менять самостоятельно

Без отдельного тестирования не следует:
- обновлять WooCommerce;
- обновлять SEOPress;
- менять тему;
- устанавливать неизвестные плагины;
- редактировать PHP-файлы;
- менять системные URL WordPress;
- включать онлайн-эквайринг;
- включать автоматические зоны доставки без согласованных границ.

Обновления делаются по схеме: **backup → staging → проверка → production**.

## Если что-то непонятно

Сначала вернитесь в **Rolls Bar → Главная**. Главный экран специально сделан как отправная точка для владельца/оператора, чтобы не искать нужные функции по всей стандартной панели WordPress.
